# FPL Glossary

Community acronyms and terms used by Fantasy Premier League managers. Use these meanings when reading user requests and when naming things in the UI or code.

## Acronyms

| Term | Meaning | Notes |
|---|---|---|
| **OR** | Overall Rank | Elite managers typically target a top 10k finish. |
| **RMT** | Rate My Team | Request for others to critique a squad, usually posted with FTs and ITB (e.g. "RMT please! 1 FT 0.2 ITB"). |
| **FT(s)** | Free Transfer(s) | Transfers available without a points cost. |
| **ITB** | In the Bank | Unspent budget, in £m. |
| **TV** | Team Value | Everyone starts at £100m; changes with player price rises/falls. |
| **BB** | Bench Boost chip | Bench players' points count for the GW. |
| **FH** | Free Hit chip | Unlimited transfers for one GW; squad reverts afterwards. |
| **TC** | Triple Captain chip | Captain scores 3x instead of 2x. |
| **WC** | Wildcard chip | Unlimited permanent transfers for one GW. |
| **Chip + number** | Planned chip GW | e.g. `WC4` = planning to Wildcard in GW4. |
| **GW** | Gameweek | |
| **BGW** | Blank Gameweek | A team has no fixture in the GW (often due to cup clashes); its players score 0. |
| **DGW** | Double Gameweek | A team plays twice in one GW (rescheduled blank fixtures); its players score for both matches. |
| **ITK** | In-the-Know | People with club connections who leak injury news or team sheets; leaks may be fake. |
| **BPS** | Bonus Points System | Per-match performance score; the top 3 players per match get 3/2/1 bonus points. |
| **BP** | Bonus Points | The 3/2/1 awarded from BPS. |
| **OOP** | Out-of-Position | Player listed in a more defensive position than they actually play (e.g. a forward listed as a midfielder) — gains more points per goal and may get CS points. Valuable. |
| **POO** | Reverse OOP | Player listed in a more attacking position than they play — fewer points per goal, no CS points. Avoid. |
| **CS** | Clean Sheet | |
| **xG** | Expected Goals | Compare with actual goals to spot over/under-performance. |
| **xA** | Expected Assists | Compare with actual assists. |
| **xGI** | Expected Goal Involvements | xG + xA. |
| **PPG** | Points per Game | Average points per appearance. |
| **PPG/M** | PPG per Million | PPG divided by price — value for cost. |
| **VAPM** | Value Added per Million | Like PPG/M but excludes appearance points: `(PPG - 2) / price`. |
| **EO** | Effective Ownership | % of managers starting the player + % captaining them (captain counted extra; TC counts more). Often viewed as Top 10k EO or EO around one's own rank. |
| **H2H** | Head-to-Head | Scoring mode: weekly matchups, 3 pts win / 1 draw / 0 loss. |
| **ML** | Mini-League | Private league set up with friends. |

## Common terms

- **Classic** — standard scoring mode where points accumulate over the season (vs. H2H).
- **Cup** — knockout competition starting GW17 among top managers from GW16, final in GW38.
- **Draft** — separate game mode where each player can only be owned by one manager in the league.
- **Premium / Heavy hitter** — £6m+ defender or £10m+ midfielder/forward; usually a captaincy option. A squad typically has 4–5.
- **Fodder / Enabler** — cheapest players (£4.0 GK/DEF, £4.5 MID/FWD) that fund premiums and usually sit on the bench ("bench fodder").
- **Bargain** — player priced well below their expected output.
- **Nailed** — expected to start every match barring injury.
- **Rotation** — risk of not starting or being subbed off frequently.
- **Bald Fraud** — Pep Guardiola, for his unpredictable line-ups (Man City rotation risk).
- **Essential / Asset** — a "must-have" player (used loosely).
- **Blank** — player returns nothing beyond appearance points (≤2 pts). Also used for a team with no fixture (see BGW).
- **Haul / Return** — a return is a goal/assist/CS etc.; a haul is a big, usually double-digit, score.
- **FPL Assist** — an assist awarded by FPL rules that isn't an official assist.
- **Hit** — spending 4 points for each transfer beyond your free transfers (`-4`, `-8`, ...).
- **Average / Top 10k Average** — GW average score; top 10k average is preferred since the overall average includes dead/inactive teams.
- **Template** — players owned by a majority of managers.
- **Differential** — low-owned player (<10% ownership) who can gain rank.
- **Punt** — short-term differential for 1–2 GWs, often before a WC.
- **Bandwagon** — a player being transferred in en masse after good performances.
- **Points-chasing** — buying a player after one big score that may not be repeated.
- **Kneejerk** — hasty transfer, often made before the GW has finished, without much thought.
- **Underlying stats** — xG, xA, shots, shots on target, key passes, crosses, etc., compared with actual output.
- **Over-/Under-performing** — actual output well above/below underlying stats.
- **Regression to the mean** — expectation that an over/under-performer's output moves back toward their underlying numbers.
- **Dead team** — manager who hasn't made a transfer in 5+ GWs.
